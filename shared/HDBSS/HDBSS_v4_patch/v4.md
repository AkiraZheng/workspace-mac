# v3->v4 总结

需要的改进点
1. 将ioctl取消（接口相关的最后再修改）
    - 对于enable：在migration初始化的时候自动enable这个特性（KVM_SET_USER_MEMORY_REGION中）
    - 对于disable：在migration结束的时候自动disable这个特性（VM stops，但是目前还没找到在哪stop的）
    - 对于size：在enable的时候，根据当前 VM 的 memory usage 来自动选择大小。
2. HDBSSBR_EL2 的define中，把 GENMASK(55, 12 + sz) 删了，换成HDBSSBR_EL2_BADDR_MASK

3. enable的代码中，把size改成order，防止歧义。

4. 修改触发hdbss flush的位置，保证一些函数的干净性

5. 测试dirty ringDirty Ring脏页统计

6. 合入leo的 HACDBS patch(解决拆大页问题)

7. 将所有HDBSS相关的特性代码归档到arch/arm64/kvm/dirty_bit.c file (plus a header such as arch/arm64/include/asm/kvm_dirty_bit.h).

8. 迁移后,在迁入端页面发生权限变化时(W->RO时),需要把DBM标志去掉

9. 将添加DBM prot的操作放到每个可读页首次fault的时候就加上，这样可以在迁移的时候再减少一次trap，更干净。(argue,涉及的修改太多了,暂时先不考虑)
