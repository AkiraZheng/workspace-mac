## 内核编译步骤

### 步骤1：检查现有编译状态

```bash
# 查看当前编译状态
ls -la arch/arm64/boot/Image
file arch/arm64/boot/Image

# 输出应为：
# Linux kernel ARM64 boot executable Image, little-endian, 4K pages
```

### 步骤2：修改必要驱动为内置（关键！）

使用自定义Image直接启动时无initramfs，必须将以下驱动改为内置（`=y`）：

```bash
# 修改内核配置
cd /root/openeuler/kernel

# virtio驱动（磁盘和网络）
sed -i 's/^CONFIG_VIRTIO=m/CONFIG_VIRTIO=y/' .config
sed -i 's/^CONFIG_VIRTIO_PCI=m/CONFIG_VIRTIO_PCI=y/' .config
sed -i 's/^CONFIG_VIRTIO_PCI_LIB=m/CONFIG_VIRTIO_PCI_LIB=y/' .config
sed -i 's/^CONFIG_VIRTIO_BLK=m/CONFIG_VIRTIO_BLK=y/' .config
sed -i 's/^CONFIG_VIRTIO_NET=m/CONFIG_VIRTIO_NET=y/' .config

# 文件系统驱动
sed -i 's/^CONFIG_FAT_FS=m/CONFIG_FAT_FS=y/' .config
sed -i 's/^CONFIG_VFAT_FS=m/CONFIG_VFAT_FS=y/' .config
sed -i 's/^CONFIG_EXT4_FS=m/CONFIG_EXT4_FS=y/' .config

# 验证修改
grep -E "^CONFIG_VIRTIO=|^CONFIG_VIRTIO_PCI=|^CONFIG_VIRTIO_BLK=|^CONFIG_VIRTIO_NET=|^CONFIG_VFAT_FS=|^CONFIG_EXT4_FS=" .config
```

**预期输出：**
```
CONFIG_VIRTIO_BLK=y
CONFIG_VIRTIO_NET=y
CONFIG_VIRTIO=y
CONFIG_VIRTIO_PCI_LIB=y
CONFIG_VIRTIO_PCI=y
CONFIG_VFAT_FS=y
CONFIG_EXT4_FS=y
```

### 步骤3：编译内核

```bash
# 更新配置并编译
make olddefconfig
make -j$(nproc) Image

# 编译完成后验证
ls -la arch/arm64/boot/Image
file arch/arm64/boot/Image
```

**编译输出位置：**
- 内核镜像：`arch/arm64/boot/Image`
- vmlinux：`vmlinux`（ELF格式，用于调试）

## 启动虚机步骤

### 步骤1：准备qcow2镜像

#### 下载镜像

```bash
# 使用脚本下载（推荐）
/root/.config/opencode/skills/qemu-vm-launcher/scripts/download-image.sh -o . -v 24.03-LTS

# 或手动下载
wget https://repo.openeuler.org/openEuler-24.03-LTS/virtual_machine_img/aarch64/openEuler-24.03-LTS-aarch64.qcow2.xz
xz -d openEuler-24.03-LTS-aarch64.qcow2.xz
```

#### 修复SSH配置（必须！）

openEuler镜像默认禁用SSH密码登录，需要修复：

```bash
# 停止所有虚机
pkill -f qemu-system-aarch64

# 修复SSH配置
/root/.config/opencode/skills/qemu-vm-launcher/scripts/fix-ssh-config.sh -i openEuler-24.03-LTS-aarch64.qcow2
```

修复内容：
- 启用SSH密码认证（`ssh_pwauth: true`）
- 防止cloud-init删除SSH keys（`ssh_deletekeys: false`）
- 设置root密码（默认：`{VM_PASSWORD}`）

### 步骤2：启动虚机

#### 方法A：直接运行QEMU命令

```bash
qemu-system-aarch64 \
  -machine virt,accel=tcg \
  -cpu cortex-a72 \
  -smp 4 \
  -m 4G \
  -kernel /root/openeuler/kernel/arch/arm64/boot/Image \
  -append "console=ttyAMA0 root=/dev/vda2 rw" \
  -drive file=/root/openeuler/kernel/openEuler-24.03-LTS-aarch64.qcow2,if=virtio,format=qcow2 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=net0 \
  -nographic
```

#### 方法B：使用启动脚本

```bash
# 启动脚本位置
/root/openeuler/kernel/start-vm-custom-kernel.sh

# 执行启动
./start-vm-custom-kernel.sh
```

### 步骤3：等待虚机启动

TCG模式（无KVM加速）启动较慢，需要等待约90秒：

```bash
# 等待启动完成
sleep 90

# 检查启动日志（若后台运行）
tail -50 /tmp/qemu.log
```

**启动成功标志：**
- 看到 `openEuler 24.03 (LTS)` 登录提示
- 显示自定义内核版本：`Kernel 6.6.0+`
- SSH服务启动：`Started OpenSSH server daemon`

### 步骤4：SSH登录验证

```bash
# SSH登录
sshpass -p '{VM_PASSWORD}' ssh -o StrictHostKeyChecking=no root@localhost -p 2222

# 或使用测试脚本
/root/.config/opencode/skills/qemu-vm-launcher/scripts/ssh-test.sh -h localhost -p 2222 -u root -P '{VM_PASSWORD}'
```

**验证成功输出：**
```
SSH连接成功
localhost.localdomain
Linux localhost.localdomain 6.6.0+ #5 SMP Thu May 14 12:31:00 CST 2026 aarch64 aarch64 aarch64 GNU/Linux
```

## QEMU命令参数详解

| 参数 | 说明 |
|------|------|
| `-machine virt,accel=tcg` | 使用virt机器类型，TCG模拟模式（无KVM时使用） |
| `-machine virt,accel=kvm` | KVM加速模式（需要/dev/kvm支持） |
| `-cpu cortex-a72` | TCG模式CPU类型 |
| `-cpu host` | KVM模式使用host CPU特性 |
| `-smp 4` | 4核CPU |
| `-m 4G` | 4GB内存 |
| `-kernel <Image>` | 自定义内核镜像路径 |
| `-append "console=ttyAMA0 root=/dev/vda2 rw"` | 内核启动参数，指定root分区 |
| `-drive file=<qcow2>,if=virtio,format=qcow2` | virtio磁盘驱动，qcow2格式镜像 |
| `-netdev user,id=net0,hostfwd=tcp::2222-:22` | 用户网络，SSH端口映射2222→22 |
| `-device virtio-net-pci,netdev=net0` | virtio网卡 |
| `-nographic` | 无图形界面，使用串口控制台 |

## 常见问题与解决

### 问题1：Kernel panic - Unable to mount root fs

**错误信息：**
```
VFS: Cannot open root device "/dev/vda2" or unknown-block(0,0)
Kernel panic - not syncing: VFS: Unable to mount root fs
```

**原因：** virtio-blk驱动是模块形式（`=m`），无initramfs时无法加载。

**解决：**
```bash
sed -i 's/^CONFIG_VIRTIO_BLK=m/CONFIG_VIRTIO_BLK=y/' .config
sed -i 's/^CONFIG_VIRTIO=m/CONFIG_VIRTIO=y/' .config
sed -i 's/^CONFIG_VIRTIO_PCI=m/CONFIG_VIRTIO_PCI=y/' .config
make olddefconfig && make -j$(nproc) Image
```

### 问题2：进入Emergency Mode - Failed to mount /boot

**错误信息：**
```
FAILED] Failed to mount /boot
You are in emergency mode
```

**原因：** VFAT驱动是模块形式，无法挂载/boot分区（EFI分区）。

**解决：**
```bash
sed -i 's/^CONFIG_FAT_FS=m/CONFIG_FAT_FS=y/' .config
sed -i 's/^CONFIG_VFAT_FS=m/CONFIG_VFAT_FS=y/' .config
make olddefconfig && make -j$(nproc) Image
```

### 问题3：SSH连接失败 - Permission denied

**错误信息：**
```
Permission denied (publickey,gssapi-with-mic)
```

**原因：** openEuler默认禁用SSH密码登录。

**解决：**
```bash
# 停止虚机
pkill -f qemu-system-aarch64

# 修复SSH配置
/root/.config/opencode/skills/qemu-vm-launcher/scripts/fix-ssh-config.sh -i openEuler.qcow2

# 重启虚机
```

### 问题4：SSH连接超时

**原因：** TCG模式启动慢，SSH服务未完全启动。

**解决：**
```bash
# 增加等待时间（TCG模式需要90-120秒）
sleep 120

# 或使用自动重试脚本
/root/.config/opencode/skills/qemu-vm-launcher/scripts/ssh-test.sh -r 20 -i 10
```

### 问题5：REMOTE HOST IDENTIFICATION HAS CHANGED

**错误信息：**
```
WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!
```

**原因：** 之前连接过同一端口但主机已更换。

**解决：**
```bash
# 清理known_hosts
ssh-keygen -R "[localhost]:2222"

# 或使用StrictHostKeyChecking=no
sshpass -p 'password' ssh -o StrictHostKeyChecking=no root@localhost -p 2222
```

## 必须内置的驱动清单

使用自定义Image启动（无initramfs）时，以下驱动必须设为`=y`：

| 驱动 | 配置项 | 用途 |
|------|--------|------|
| virtio核心 | CONFIG_VIRTIO=y | virtio总线 |
| virtio PCI | CONFIG_VIRTIO_PCI=y | virtio PCI设备 |
| virtio_blk | CONFIG_VIRTIO_BLK=y | virtio磁盘驱动 |
| virtio_net | CONFIG_VIRTIO_NET=y | virtio网卡驱动 |
| ext4 | CONFIG_EXT4_FS=y | rootfs文件系统 |
| vfat | CONFIG_VFAT_FS=y | /boot分区（EFI） |
| fat | CONFIG_FAT_FS=y | FAT文件系统核心 |

## 附录：完整启动脚本

```bash
#!/bin/bash
#========================================
# qcow2虚拟机启动脚本（自定义内核）
#========================================
# 内核: /root/openeuler/kernel/arch/arm64/boot/Image
# 说明: 使用自定义编译的内核Image，无initramfs
#       qcow2作为磁盘，内核直接挂载rootfs
#
# SSH连接方式:
#   ssh root@localhost -p 2222
# 
# 登录账号: root
# 登录密码: {VM_PASSWORD}
#
# 或使用sshpass自动登录:
#   sshpass -p '{VM_PASSWORD}' ssh -o StrictHostKeyChecking=no root@localhost -p 2222
#========================================

qemu-system-aarch64 \
  -machine virt,accel=tcg \
  -cpu cortex-a72 \
  -smp 4 \
  -m 4G \
  -kernel /root/openeuler/kernel/arch/arm64/boot/Image \
  -append "console=ttyAMA0 root=/dev/vda2 rw" \
  -drive file=/root/openeuler/kernel/openEuler-24.03-LTS-aarch64.qcow2,if=virtio,format=qcow2 \
  -netdev user,id=net0,hostfwd=tcp::2222-:22 \
  -device virtio-net-pci,netdev=net0 \
  -nographic
```
