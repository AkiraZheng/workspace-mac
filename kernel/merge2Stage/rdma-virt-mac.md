# 虚拟地址空间标识

**内核空间特征：**
- 最高位（bit 63）= 1
- 所有内核虚拟地址都以 `0xFFFF` 开头
- 范围：`0xffff000000000000 - 0xffffffffffffffff` (128TB)

**用户空间特征：**
- 最高位（bit 63）= 0
- 范围：`0x0000000000000000 - 0x0000ffffffffffff` (128TB)

**示例：**
```
0xfffffc0006000000
▲▲▲▲
高位全为1 → 内核空间
有效位：低48位 = 0xfc00_0600_0000
```

硬件通过检查最高位快速判断地址空间类型。

# 内核页表布局解析

`/sys/kernel/debug/kernel_page_tables` 输出的是**内核虚拟地址空间的页表布局**：

**主要区域：**
- `Linear Mapping` - 物理内存的线性映射
- `vmalloc()` - 动态分配内存区域
- `Fixmap` - 固定映射区域
- `PCI I/O` - PCI设备I/O空间
- `vmemmap` - 页面描述符数组映射

**未映射空洞：**
```
0xfffffe0000000000-0x0000000000000000    2T PGD
```
- 这是vmemmap结束到用户空间之间的未使用区域（wrap-around）
- 不是内核和用户空间的范围，而是内核空间内部的gap

**注意：** 此debugfs只dump内核页表，用户空间页表需通过 `/proc/<pid>/maps` 等查看。
